Bumblebee

Everything Bumblebee needs is included: Ollama, ffmpeg and whisper are built in, so nothing else has to be installed.

During installation, Bumblebee checks your Mac's chip and memory and downloads the AI models that suit it: a reply model, a small search model, and a speech-recognition model. On a Mac with 8 GB of memory that is about 3.3 GB; Macs with more memory get larger, better models. The installer stays on "Running package scripts" while this downloads, which can take several minutes.

Everything then runs on this Mac. Your media and conversations never leave it.
